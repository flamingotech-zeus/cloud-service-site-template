# 云服务官网模板

[English](README.md) | [简体中文](README.zh-CN.md)

> 一个轻量的多页产品官网 —— 31 个静态 HTML 页面，不用框架，不用构建。

> **说明。** 这个仓库里带有具体公司的内容 —— 品牌文案、标志、资源路径。真正值得拿走的是版式、动效和代码。发布前请先替换内容。


## 这是什么

这不是一个框架脚手架。没有 React，没有 Tailwind，没有打包器。

它是另一条路：纯 HTML 页面配纯 CSS，外加一个新闻归档。整个东西小到可以一次读完，而这正是重点 —— 有些产品官网不需要构建流水线，这里展示的是这么做能做成什么样。

## 为什么开源

这个站是给我们自己的一项服务跑的。后来结构被判断为可复用，就把它和内容分开了。

能迁移的是页面组织方式、共用的布局思路和新闻归档那一套。把文案换掉，就是别的项目的起点。

## 里面有什么

- **31 个 HTML 页面。** 含首页、关于、公司、联系、404，以及按日期命名的新闻归档。
- **零依赖。** 没有要装的、没有要升级的、也没有会在版本变动时坏掉的东西。
- **实测体积小。** 35 个文件约 420 KB。
- **按日期命名的新闻模式。** 每篇文章一个页面、以日期命名，不用 CMS 也能让归档可导航。

## 环境要求

任意静态文件服务器。

## 怎么开始

把目录起成服务再打开：

```bash
python -m http.server 8000
# 然后访问 http://localhost:8000
```

也可以直接打开 `index.html`。

## 注意与边界

1. **共用标记是复制的，不是模板化的。** 没有构建步骤就没有 include 机制，改一次页头要动每一个页面。这是"不要工具链"换来的代价。
2. **原始目录里有构建产物，应该删掉。** `_build` 是产物，不是源码。
3. **内容是具体公司的。** 把文案、公司信息和联系方式换掉。
4. **新闻页的日期是过去的。** 它们作为结构示例保留，不是线上内容。
